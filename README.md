# 🛍️ Shop Application

A full‑stack e‑commerce application built with:

- **Frontend:** React, Vite, TailwindCSS  
- **Backend:** ASP.NET Web API  
- **Database:** (SQL Server / PostgreSQL / SQLite — choose your own)

This project is structured into two main folders:
/FRONT   → React + Vite + Tailwind
/API     → ASP.NET Web API
---

## 🚀 Features

### ✅ Frontend (React)
- Modern UI built with **Vite + React**
- **TailwindCSS** for fast styling
- Product listing & product details
- Shopping cart management
- Responsive design
- API communication via Axios/Fetch

### ✅ Backend (ASP.NET)
- RESTful API built with **ASP.NET Web API**
- Clean architecture (Controllers → Services → Repositories)
- Authentication (JWT) — optional
- CRUD endpoints for products, categories, users, orders
- Secure input validation
